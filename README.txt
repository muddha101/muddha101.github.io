배요섭 개인 웹페이지 — GitHub에 올릴 파일

이 폴더 안의 내용(index.html, data 폴더, img 폴더)을 GitHub 저장소 맨 위에 그대로 올리면 됩니다.
폴더 구조를 바꾸지 마세요. 페이지가 data/site.json과 img/ 안의 사진을 이 위치에서 찾습니다.

페이지 주소
  홈 (영문)      /#en      홈 (한글)      /#ko
  뛰다 (영문)    /#tuida   뛰다 (한글)    /#tuida-ko
  궁리소묻다     /#muddha  궁리소묻다(한글) /#muddha-ko

글을 고칠 때: data/site.json 한 파일만 바꾸면 됩니다.
사진을 바꿀 때: img/ 에 사진을 넣고 data/site.json 에 그 파일 이름을 적습니다.
